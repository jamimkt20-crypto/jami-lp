# LP Jamili — link da bio

Site estático (HTML + CSS + JS), sem build. Pronto para a Vercel.

```
index.html          página
assets/styles.css   estilos, animações e versão celular
assets/main.js      efeito de textos surgindo ao rolar
assets/img/         fotos
vercel.json         configuração da Vercel (cache das imagens)
```

Deploy: importar a pasta na Vercel com Framework Preset "Other", sem comando de build e com Output Directory em branco.
